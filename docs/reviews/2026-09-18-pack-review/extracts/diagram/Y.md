**What it makes the agent do:** A bounded "Fast authoring path": (1) pick a diagram `type`; (2) read exactly one schema, `schemas/common.schema.json`, and one matching example — "Read only those files"; (3) "Artifact first: the next tool action must write the candidate... It also directs an "Update awareness" step (run `scripts/check-update.mjs` once, show at most one compact notice, never auto-update — "silence is never consent"), a post-delivery `visual-check` browser-evidence step, and a mandatory manual "Perceptual delivery gate" (inspect the real HTML at four viewports/two themes) before reporting one of `visual_review: passed|skipped|failed`. It ends by requiring a fixed handoff receipt (diagram type, output path, both SHA-256 hashes, validation summary, `browser_evidence`, `visual_review`, `correction_rounds`).

**Enforcement:** Executable, not prose-only. `bin/archify.mjs` implements `render/validate/deliver/compare/migrate/preview/check/visual-check/guide/brands/doctor/demo` as real subcommands. `deliver` stages output in a private same-directory temp dir, runs `scripts/check-render-output.mjs` (parses the SVG, checks finiteness, orthogonality, crossings, corridors, border runs, label clearance, route rhythm, desktop readability) and only atomically renames the candidate into place if all checks pass; on any failure it exits non-zero, deletes staging state, and "preserves the previous trusted artifact" (fails closed). `bin/visual-check.mjs` drives real headless Chrome/Chromium over the DevTools protocol pipe, measures containment/readability/chrome-clearance at four viewports, captures PNG screenshots, and writes a JSON receipt; exit 0 = pass, 1 = fail, 2 = skipped only when Chrome is unavailable (explicitly documented: "Runtime or capture failures leave incomplete evidence and must not be normalized to `skipped`"). `scripts/check-update.mjs` is a fully implemented, lock-protected, atomic cache/version-check state machine (fails closed to `silent`/cache-unavailable on any inconsistency) rather than a stub.

**Dependencies:** Node.js ≥18 (declared in `package.json` `engines`); no `npm install` required at runtime per SKILL.md ("No install is required inside the skill package"). `devDependencies` (`ajv`, `parse5`, `saxes`, `simple-icons`) are build/test-only. `visual-check` and `preview` need an optional local Chrome/Chromium binary (auto-detected or via `ARCHIFY_CHROME`); its absence degrades to a documented "skipped" exit code rather than failing. `gh` appears only inside two test files (release/packaging gate tests), not in the runtime authoring/delivery path.
