# Migration record

`../..//MIGRATION.md` (repo root) is the row-by-row historical record of the
2026-08-09 machine-wide skill migration.

`harness/` is a verbatim archive of the migration harness project
(`~/ref/skill-organization` as-run): CONFIG, STATE with full evidence log,
phase runbooks, validator/template sources, and the `/phase` dispatch skill.
To reproduce this migration on another machine, start from the maintained
template (`skill-organization-template`), not this archive — the template
carries post-retro runbook fixes; this archive is the as-run record.
