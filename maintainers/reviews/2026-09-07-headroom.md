# headroom

**Verdict:** HARVEST. One design technique (marker-block merge-and-carry-forward
for accumulated lessons) fills a gap retro names as unbuilt; the product itself,
a local context-compression proxy for AI agents, targets provider cache economics
at API-key scale, which this machine has not evidenced as a cost, and carries an
upload beacon that is on by default.

**Ancestry:** none. Checked grep for skill-library, gfmcloud, graham across the
clone, CHANGELOG cross-references, and SKILL.md files (there are none).

## Method

Clean-room review at the CLI default model with Read, Glob, Grep and read-only
git allowed; the permission layer denied git anyway, so cadence came from
CHANGELOG release dates (21 releases 2026-05-26 to 2026-08-27). Comparison by
one Sonnet subagent against retro, skill-discovery, transcript-scanner, handoff,
llama-offload, model-effort-advisor, proof-of-work, evidence-report,
rulings-harness, and the global CLAUDE.md; it ran git log and confirmed the
shape. No install, build, or test script from the source was run.

## What landed

- Row 1: retro section 6 now names Headroom's merge-and-carry-forward technique
  (`headroom/learn/writer.py`, `_merge_recommendations`) as the reference for
  the unbuilt `/retro-review`, with its limit: promotes idempotently, never
  demotes. Target `plugins/workbench/skills/retro/SKILL.md`, this commit.

## What was declined, and why

- Rows 3, 4, 5 (Graham, "1 hold"): three one-line principles for the global
  CLAUDE.md, held because none has cost a correction on this machine. Candidates
  kept here so a future correction can pull the wording:
  - Telemetry two-switch: local collection and upload are separate switches;
    turning on local stats is not consent to upload, and an upgrade must not
    start uploading (beacon.py:18-20). Target: Credentials and secrets.
  - Refuse to silently ignore a user-supplied override; raise instead of
    dropping it (smart_crusher.py:36-40). Target: Surgical edits.
  - A default policy is one named constant, one line to audit and one to
    reverse (beacon.py:52-55). Target: Boundaries are declared and enforced.
- Row 11 (Graham, "2 no"): do not install `headroom wrap claude`. Standing proxy
  in the credential path, about 1,182 resolved packages, writes to
  `~/.claude/settings.json` and `~/.claude.json`, a PreToolUse hook that shells
  out on every Bash call, beacon on by default, and an OAuth token written to
  disk while SECURITY.md says no credential storage.
- Row 2: shared-file migration trick; retro never writes to shared files.
- Rows 6, 7, 9: cache-prefix freezing, comparison-key safety, telemetry label
  truncation; sound ideas with no consumer on this machine.
- Row 8: "an unreproducible number is a liability"; proof-of-work and
  evidence-report already state it more operationally.
- Row 10: `headroom learn` as a whole; it gives up path:line provenance and
  per-lesson human routing, which retro rejects by design.
