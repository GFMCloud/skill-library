# ai-memory

**Verdict:** SKIP. A well-engineered, heavily tested Rust memory server (8,558 stars, MIT,
v2.4.1, 121 releases in four months) whose every transferable idea is either already done
here or has no consumer: redaction patterns are already anchored to the published key format
(`~/.claude/hooks/memory_safety.py:22`), "retrieved memory is untrusted" is stronger in
session-carryover.py (it names the escape hatch and re-runs typed checks), the incumbent
README already states where its own claims overreach, and decay, cross-agent transport, and
a Rust type boundary solve problems a one-operator, one-CLI, files-as-truth machine does not
have. Its AGENTS.md block tells agents to route durable facts to its server instead of the
harness's files, which contradicts the standing rule that files are the source of truth.
Memory design is the Thursday maintainer's (S-2). The first SKIP in thirteen clean-room
reviews.
