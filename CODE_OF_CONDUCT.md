# Code of conduct

## The rule

Be decent to people. That covers issues, pull requests, comments and anything else that happens here.

## What that means in practice

- Assume the other person is trying to help.
- Criticize the work, never the person.
- Do not post anyone's personal information, including your own.
- No harassment, insults, or unwelcome attention of any kind.
- If someone tells you to stop, stop.

## If something goes wrong

There are two ways to report it, and you can use both.

- **To GitHub.** Open the "..." menu beside the comment, issue or pull request and choose "Report content". That report goes to GitHub's staff, not to this project.
- **To the maintainer.** Open an issue that says only that you have a conduct concern. Leave out names and details, because issues are public. The maintainer will reply there and arrange a private way to talk.

This library is maintained by one person, so there is no promised response time.

## Consequences

The maintainer may edit or remove comments, close issues, or block an account, and will say why.

## Scope

This applies in this repository and anywhere someone is representing this project.
